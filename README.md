# BM Tahun 4 Vocabulary Adventure

Permainan interaktif kosa kata Bahasa Melayu Tahun 4.

## V1.0

- Peta unit pembelajaran
- Profil nama murid, bintang dan XP
- 10 mode permainan
- Unit 1 dengan data contoh sementara
- Paparan responsif untuk komputer, tablet dan telefon

## Mode permainan

1. Flash Card
2. Word Catch
3. Matching
4. Typing
5. Listening
6. Boss Battle
7. Treasure Hunt
8. Sentence Builder
9. Word Detective
10. Word Factory

## Struktur

- `index.html` — halaman utama
- `styles.css` — reka bentuk
- `data.js` — unit dan kosa kata
- `app.js` — enjin permainan

Kosa kata sebenar setiap unit akan dimasukkan ke dalam `data.js`.
